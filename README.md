# Apocalypse Cyber — Shadow Survivor

Jogo 2D de plataforma mobile feito para rodar diretamente no navegador.

## Como jogar pelo GitHub
1. Crie um repositório no GitHub.
2. Envie `index.html`.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, escolha `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve. O GitHub Pages publicará o jogo.

Não precisa de Unity, Node, servidor ou biblioteca externa.

## Controles
- Celular: botões na tela.
- PC: A/D ou ←/→ para andar; Espaço/W/↑ para pular; J lâmina; K dash; L camuflagem.

## Conteúdo
- Plataforma 2D lateral.
- Pulo duplo.
- Lâminas de plasma.
- Dash elétrico com invulnerabilidade breve.
- Camuflagem temporária.
- Saqueadores, drones, serras, lasers e resíduos tóxicos.
- Checkpoint.
- Parallax em 4 camadas.
- HUD de vida, munição e recargas.
- Final de fase.
- Tudo em um único `index.html`, facilitando colocar no GitHub.

O jogo usa identidade visual e código originais, inspirado no gênero de plataforma/ação, sem copiar assets, fases ou código proprietário de outros jogos.
