# Arashi Fabricio

Jogo web 2D original, feito para rodar em navegador e ser hospedado no GitHub Pages.

## Recursos
- Plataforma 2D, corrida, pulo e pulo duplo
- Dash
- Shuriken ilimitado
- Ataque corpo a corpo
- Inimigos corpo a corpo e à distância
- Armadilhas
- Checkpoints
- Chefes a cada 20 fases
- 80 fases estruturadas por biomas
- Moedas e árvore de habilidades
- Salvamento local no navegador
- Controles de teclado e toque
- Efeitos românticos opcionais
- Português do Brasil

## GitHub Pages
1. Crie um repositório chamado `arashi-fabricio`.
2. Envie `index.html`, `style.css` e `game.js`.
3. Em Settings > Pages, escolha `Deploy from a branch`, branch `main`, pasta `/root`.
4. Abra o endereço do GitHub Pages.

Este projeto usa somente HTML/CSS/JavaScript e não depende de servidor.
